Mithril — Getting Started & Architecture Guide




Mithril is a lightweight, standalone LLM inference engine written in Rust. Single binary, no runtime dependencies. Serves GGUF models via Ollama-compatible API, OpenAI-compatible API, and MCP stdio.

# .mithril/fellowship.yaml
name: "gemini-plan-kiro-build"

router:  # global fallback
  provider: gemini
  model: gemini-3.6-flash
  confidence_threshold: 0.9

agents:
  - name: "architect"
    provider: gemini
    model: gemini-2.5-pro
    role: "Designs solutions, analyzes problems"
    router:
      provider: gemini
      model: gemini-3.6-flash
      trigger: "design|plan|architecture|refactor"
      confidence_threshold: 0.7
    tools: ["read_psi", "grep_files", "search_symbols"]
    can_delegate_to: ["coder"]

  - name: "coder"
    provider: groq
    model: llama-3.3-70b-versatile
    role: "Fast code implementer"
    router:
      provider: local
      model: qwen-1.5b
      trigger: "implement|write|fix|edit|test"
      confidence_threshold: 0.6
    tools: ["*"]

  - name: "executor"
    type: external
    binary: kiro-cli
    args: ["chat", "--trust-all-tools"]
    role: "External execution via Kiro CLI"
    router:
      provider: gemini
      model: gemini-3.6-flash
      trigger: "run|deploy|build|execute"
      confidence_threshold: 0.7
# ~/.mithril/config.yaml
permissions:
  run_terminal: allow    # Never ask
  delete_file: deny      # Completely disabled
  write_file: ask        # Confirm each time

# Bypass for a session:
mithril chat --no-confirm
LevelBehavior
allowExecute immediately
askPrompt user [y/N]
denyTool disabled (LLM gets error)

Sandbox: Blocks rm -rf /, sudo, fork bombs. Credentials: Argon2id + AES-256-GCM.

# .mithril-flow.yaml
version: "1.0"
name: "Gemini + Tools"
max_iterations: 10
planner:
  name: "Gemini"
  provider: gemini
  tools: [read_psi, write_file, edit_file, apply_patch,
          grep_files, run_terminal, git_status, git_diff]

Algorithm: Planner → tools → execute → feed results → repeat (up to max_iterations)
